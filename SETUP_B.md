## PART 2 — CLIENT DESIGN BRIEF

### PULSE RUN CO.

**Project Statement**
Pulse Run Co. is a Quezon City-based running gear and training-app company relaunching its brand identity to support three simultaneous initiatives: (1) a new trail-running shoe product line, (2) a mobile/web training and run-tracking app, and (3) its first appearance at a regional running & fitness expo. The client has engaged you as their Visual Graphic Design NC III candidate/contractor to produce the complete visual design package across all touchpoints.

**Project Objectives**
- Establish a bold, energetic, and motivating brand identity centered on "every run is progress" (the brand's *pulse* — momentum — positioning).
- Ensure visual consistency across print, digital (UX/UI), packaging, and physical (booth) touchpoints.
- Appeal to urban runners and fitness enthusiasts (ages 18–40) who value performance, progress tracking, and community.

**Brand Personality & Mood**
Energetic, bold, dynamic, motivating — not corporate, not cluttered. Think high-contrast color blocking, diagonal/directional layout cues, and strong geometric sans-serif typography.

**Target Audience**
Urban runners and fitness enthusiasts, 18–40 years old, who train for races using apps, care about performance gear, and respond to motivational, achievement-driven branding.

**Suggested Color & Style Direction**
- Palette: high-energy primary (electric blue or neon green) with a contrasting accent (orange or magenta), grounded by black/white
- Style: bold geometric shapes, dynamic diagonals, strong contrast — avoid soft pastels or overly delicate ornamentation
- Typography: bold geometric or condensed sans-serif; avoid script/novelty fonts as primary type

**Constraints**
- Budget: mid-range production (standard offset/digital printing, standard packaging materials, modular booth build)
- Timeline: single-day turnaround for this assessment cycle
- Technical feasibility: all deliverables must be producible with standard design software and SketchUp (for the booth)

**Deliverables Required (mapped to Core Units)**
1. Logo for Pulse Run Co.
2. A print poster announcing the new trail-running shoe launch (or a tied-in race event)
3. UX flow + UI screens for the Pulse training/run-tracking app (Normal/desktop-tablet and Mobile)
4. Packaging design for the new trail-running shoe (shoebox, with die line)
5. A booth/kiosk design for Pulse Run Co.'s race-expo appearance, modeled in SketchUp

**References / Bibliography**
Candidates should rely on the assets provided in the Drive's `Assets/` folder (downloaded during the 15-minute window) plus general design knowledge. No live internet research is available after the download window closes.

> **Note to Proctor:** Populate the Drive's `Assets/` folder before the session with: Pulse Run Co. name/wordmark reference (no existing logo — candidates design from scratch), 3–5 running shoe/athlete-in-motion photos, 2–3 texture/background images (track, asphalt, gradient), and any brand fonts you want candidates to use. This packet does not include binary image assets — only the brief and instructions.

## PART 3 — PER-UNIT TASK SPECIFICATIONS

### Unit 1 — Develop Designs for a Logo (ICT216313)
**Folder:** `01_Company_Logo/`
**Objective:** Design a logo for Pulse Run Co. reflecting the brand's bold, energetic identity.
**Required elements:**
- Primary logo (full color, on light background)
- Monochrome/1-color variant
- Submit in both vector source and export
**Deliverable files:** `Pulse_Logo.ai` (or `.cdr`) + `Pulse_Logo.pdf`
**Evidence checkpoints (per TR Evidence Guide):** interpreted the brief; explored sketches/design concepts; applied appropriate color/typography; finalized with documented color codes (HEX/CMYK).

### Unit 2 — Develop Designs for Print Media (ICT216314)
**Folder:** `02_Company_Poster/`
**Objective:** Design a product-launch poster for the new trail-running shoe.
**Required elements:**
- Size: A3 portrait (297mm × 420mm), 300 DPI, CMYK, 3mm bleed
- Must include: finished logo (Unit 1), product name/tagline, key visual, launch details (date/location placeholder)
**Deliverable files:** `Pulse_Poster.psd` (or `.ai`) + `Pulse_Poster.pdf`
**Evidence checkpoints:** correct page/document setup; layout using design principles; print-ready export (bleed, resolution, color mode).

### Units 3 & 4 — Develop Designs for User Experience & User Interface (ICT216315 / ICT216316)
**Folder:** `03_Company_Mockup/` → subfolders `Normal/` and `Mobile/`
**Objective:** Design the training-log/run-tracking flow (UX) and screen designs (UI) for the Pulse app, for both a normal (desktop/tablet) layout and a mobile layout.
**Required elements:**
- UX: simple flowchart/wireflow of the core journey (Home → Start Run/Training Plan → Live Tracking → Run Summary → Progress History)
- UI: at least 2 designed screens per platform (e.g., Home + Run Summary), using consistent brand colors/typography from Unit 1
- `Normal/` = desktop or tablet screen dimensions (e.g., 1440×1024px)
- `Mobile/` = smartphone screen dimensions (e.g., 375×812px)
**Deliverable files:**
- `Normal/`: `Pulse_UX_Flow.pdf`, `Pulse_UI_Normal.psd`/`.ai` + `.pdf`
- `Mobile/`: `Pulse_UI_Mobile.psd`/`.ai` + `.pdf`
**Evidence checkpoints:** interpreted UX requirements; produced wireflow; created page template/wireframe; finalized UI screens per platform.

### Unit 5 — Develop Designs for Product Packaging (ICT216317)
**Folder:** `04_Product_Packaging/`
**Objective:** Design packaging for the new trail-running shoe (shoebox).
**Required elements:**
- Flat/unfolded die-line layout with cut/fold lines clearly marked
- Applied final design within the die line (top, bottom, side panels as applicable)
- Include logo, product name, size/spec placeholder, brand colors
**Deliverable files:** `Pulse_Packaging_DieLine.ai` + `Pulse_Packaging_Final.pdf`
**Evidence checkpoints:** design ideas explored via research/sketches; mockup created; final design finalized within die line with documentation of materials/measurements.

### Unit 6 — Design Booth and Product/Window Display (ICT216318)
**Folder:** `05_Design_Booth_Kiosk/`
**Objective:** Design a race-expo booth/kiosk for Pulse Run Co., modeled in SketchUp.
**Required elements:**
- 3D SketchUp model of the booth, incorporating brand colors, logo, and signage from Units 1–2
- At least 3 rendered/exported views (e.g., front, isometric/3D perspective, side)
- Reasonable real-world booth dimensions (e.g., 3m × 3m standard expo booth footprint)
**Deliverable files:** `Pulse_Booth.skp` + `Pulse_Booth_View1.jpg`, `Pulse_Booth_View2.jpg`, `Pulse_Booth_View3.jpg` (or combined into one `Pulse_Booth_Views.pdf`)
**Evidence checkpoints:** interpreted booth/display requirements; developed design concept; finalized with accurate measurements/materials; produced colored 3D model views.
